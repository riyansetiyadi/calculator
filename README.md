# Kalkulator Simpel

Aplikasi kalkulator berbasis HTML, CSS, dan JavaScript murni (Vanilla JS) yang simpel, responsif, dan mudah digunakan.

## Demo
Coba di sini: [https://riyansetiyadi.github.io/calculator/](https://riyansetiyadi.github.io/calculator/)

## Fitur Utama
- **Desain Simpel & Responsif**: Tampilan bersih dan nyaman digunakan di perangkat desktop maupun HP.
- **Dukungan Keyboard**: Mendukung input dari keyboard fisik (angka `0-9`, operator `+ - * /`, `Enter` atau `=` untuk menghitung, `Backspace` untuk hapus 1 karakter, serta `Escape` atau `C` untuk bersihkan layar).
- **Evaluasi Aman & Robust**: Perhitungan matematika diproses secara aman dengan penanganan kesalahan (*error handling*) tanpa *crash*.
